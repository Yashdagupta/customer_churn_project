# 📊 Customer Churn Analysis | End-to-End Data Analytics Project

## 📌 Project Overview
This project focuses on analyzing customer churn to understand customer behavior, identify churn patterns, and generate meaningful business insights using Python and SQL.

The project follows an end-to-end data analytics workflow, from data cleaning and preprocessing to exploratory data analysis and visualization.

## 🎯 Business Objectives
- Analyze customer churn and retention patterns.
- Identify customer segments with higher churn.
- Compare churn across subscription types and states.
- Analyze monthly revenue trends.
- Generate insights to support customer retention strategies.

## 🛠️ Tech Stack
- **Programming Language:** Python
- **Database:** SQLite
- **Query Language:** SQL
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Environment:** Jupyter Notebook

## 🔄 Project Workflow
1. Data Loading & SQL Database Connection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Business Insights & Findings

## 📊 Key Analysis Areas
- Customer Churn Analysis
- Subscription Type Analysis
- State-wise Churn Rate
- Monthly Revenue Analysis
- Customer Behavior and Cancellation Trends

## 💡 Skills Demonstrated
- SQL Querying
- Data Cleaning and Preprocessing
- Exploratory Data Analysis
- Data Manipulation using Pandas and NumPy
- Data Visualization
- Business Insight Generation
- Python and SQL Integration

## 🚀 Project Outcome
This project demonstrates the practical application of Python and SQL in analyzing customer data, identifying churn patterns, exploring revenue trends, and generating business insights to support customer retention strategies.
